---
name: game-model
description: 在 ai_test 的游戏包中，从玩家先验和实际对局建立、校正与验证游戏专用的离线模型；适用于算分、配装、战力或成长缺口。
---

先读取当前游戏的 game.json、knowledge.md 和可回放的现场证据。专业模型适合回答反复出现且能被观测的决策问题。玩家已知的规则直接记来源；Agent 从一局中推出来的关系记为待验证假设。

1. 写下问题、输出和验证时机。例如算分在结算时核对，成长缺口要在之后几轮验证。选一份真实输入快照，记录版本、现场截图和会改变结果的条件。看不清的值保留未知。
2. 在该游戏的 models/ 写一个离线 Python 文件，提供 predict(state) 返回 JSON 对象。需要固定参数时在配置中填 settings，通过同名关键字接收。输出可复查的中间步骤、所用假设、例外和未知。随机效果可返回范围或分支。
3. 在 game.json 的 models 中登记 entry、revision。纯函数才选择 cache；外部计算依赖在 dependencies 中列出。可选 render_prediction(state, result, path) 负责本游戏的交互视图。
4. 通过 tools/game.py 的 model 命令在本局快照运行，保存原预测，再用 rsi prepare 关联输出或模型页。实际执行后用 finish 链接新截图、核对结果。偏差要分别检查识别、模型和游戏规则，留下反例。
5. 用另一手牌、另一套配装或另一局未参与调参的状态再检验。记录模型修订号和输入，能复现的偏差再登记问题，或用 memory 保存带适用条件的经验。

命令、输入格式和一个可运行的历史实例见项目 docs/game-packs.md。
