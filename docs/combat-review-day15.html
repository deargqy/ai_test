战斗模型改成两层证据链

我方：开场力量 → 多段物伤 → 背部被动产盾 → 失盾强化手部 → 更多物伤
肩部获得坚固 → 肩部转伤；无人机部署 → 力量 → 支援物伤/护盾链
敌方：开场450感电 → 雷电伤害 → 背部产盾；肩命中 → 感电百分比增长
感电/寒冷/燃烧概率产坚固 → 甲被动随机加速 → 更多状态触发

以上箭头有词条依据；时序、次数、乘区和每条边的实际边际收益尚未完整验证。敌方不是没有联动，而是这场统计中未形成足以压住我方双核的实际输出。不能由一场胜利推出力量强于感电。

启动层：敌开场禁用2.5秒与我开场加速3秒重叠；每3秒随机充能3秒不能保证落到手/肩。禁止直接拿CD减3秒算首击，缺动画/命中时间就留未知。

兑现层：手10段、肩9段是能力上限；肩本场285坚固≠9×95=855。可能受打断、死亡截断或统计口径影响，不能假定每次全段兑现。双方统计计数x1/x21/x36不换算成完整施法次数。

支援层：无人机没有直接伤害行但贡献48力量；甲没有主动护盾行，力量增伤被动仍可能生效。配件分配要比较替换前后整条链，不把伤害占比当边际收益。

状态层：战后手21.8K、肩26.0K是已增长画面，不能写回开场基础伤害。战后肩8.2、甲10.6秒单独记录；不能直接覆盖此前8.1/10.5的战前快照。表中CD只是静态比较代理，真实首击必须重新观察。
