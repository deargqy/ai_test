战力模型

面对眼前这个对手，我方靠什么启动、能打出几轮、又会被什么条件截断？

先按本局机师的技能核对哪些判断需要调整。

当前局需要读取什么

  • 双方开战前的生命、已有护盾、核心装备单击与段数、面板冷却、开场资源及状态
  • 双方确定与随机的充能、加速、禁用、护盾、成长来源，以及它们作用的对象和时机
  • 可比较的历史对手和差异；战后再补首击、首盾、前两轮、伤害与防御分项及截图

判断顺序

  1. 先判断能否启动。分开列出装备就绪、实际命中、首盾生效和敌方首轮爆发。针对同槽控制、随机禁用或随机充能分别推演；时序缺失就保留多个可能结果。
  2. 再比较有效输出与生存。单击乘段数给出全部命中时的面板基线；同时列出核心被封、仅副手出伤或首盾来不及生效的分支。双方按同一口径比较。
  3. 最后判断能否进入下一轮。核对触发的前置条件、目标、反馈和增长是否来得及兑现。在操作前把最能区分这些分支的现象写成预测，战后回到原图逐项核对。

给下一步决策的输出

  • 本场有把握的判断、成立条件、可能反转判断的未知项
  • 要核对的关键事件，例如我方首盾能否赶在对手爆发前，核心在前两轮是否出现有效命中

当前由 Agent 按证据逐场判断。面板冷却无法直接给出首击时间；战报缺行也无法证明具体哪次控制命中。尚无经校准的胜率或完整战斗模拟。
