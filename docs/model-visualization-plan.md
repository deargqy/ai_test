# 战力与配件模型可视化

基线：配装图、败局模型、对手库和BD讨论分散在多个HTML。配装搜索是静态几何模型；战斗缺首次有效命中、控制目标和新配置终局统计。假设：统一入口、可点击端点图和机制链能让人更快看懂依据并发现遗漏。

沿用现有静态HTML/JS与JSON，不操作游戏、不部署、不提交推送、不另建worktree。用户已授权自动整理和可视化，采用轻量单页而非完整战斗模拟器。保留旧历史页面，新增models.html总览并接入RSI导航。

可视化：
- 配件页从第17天实际快照生成21孔、10配件。点选配件显示端点、受益装备和遮挡；复选移除仅改变浏览器里的静态假设。伤害/段数/盾/CD与真实战斗分开，动态加速和成长不冒充已模拟。
- 战力页按启动、输出、生存筛选触发链；显示生命、科技和面板CD参考轴，首击未知。用林弦、Rogas、Ranka作为历史对照，缺值不画成0。
- 案例入口与后续升级目标、模型边界、证据链接集中展示。第17天是最后验收快照，终局结果未知，不显示仍在游戏进行中。

- [x] 实现可复用静态计算模块和页面，生成数据文件供file://离线加载。

规则：不从战后统计推导确定开场值；无人机使用本轮实测增量表；不输出总战力或胜率。配件移除是探索，不是购买建议或实机验证。
