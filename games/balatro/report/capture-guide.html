用 Steam 取得本次原图

在保存游戏截图的电脑运行 screenshot mark，将游戏置于前台，按一次 Steam 截图键（默认 F12），再用 screenshot read 读取游戏 2379780 的新原图。每次换目标重新标记，整批采齐后一起裁图、读取。

python tools/game.py --game balatro screenshot mark

python tools/game.py --game balatro screenshot read --marker "<标记路径>"
